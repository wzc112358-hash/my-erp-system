# 三个新增站点接入结果与员工验收计划

实测日期：2026-07-16。选择依据来自招投标信息获取中的员工分工、ERP 产品、群聊样本和站点真实页面，不包含任何账号或密码。

## 本批选择

### 1. 中国石油招标投标网

- 公开页面可按产品词搜索公告；新浏览器档案首次搜索会出现图片验证码，应用会停在验证页并等待员工完成。
- 公告详情可直接读取数量、技术标准、交货地点、资质、截止时间等正文。
- 群聊样本中化工产品命中密度高，适合作为本批第一站。
- 实现方式：员工可见 Browser Session + 通用 LLM 页面抽取；保留日期、公告阶段、URL 和结果结构的确定性校验。站点接口内容存在加密时，不依赖私有接口解密。

### 2. 中化采购供应链平台

- 首页公开展示招标、非招采购和竞价信息。
- 详情页能取得带签名的公告 PDF，适合直接进入现有 PDF.js/OCR 文档链路。
- 群聊样本中的相关化工物料数量较多。
- 实现方式：公开列表抽取 + PDF 文档读取；文本型 PDF 直接解析，扫描型 PDF 才调用配置的 OCR。

### 3. 云梦泽智慧平台

- 正确入口为公开门户，旧的 `#/home--` 地址已失效。
- 可按产品词、公告类型、采购方式和发布时间筛选；搜索结果同时包含招标、询比、候选人、成交结果和过期公告，因此必须做严格阶段与时效过滤。
- 详情页公开展示 PDF.js 正文和附件；实测可读到数量、标准、商务条款和供应商要求。
- 实现方式：通用浏览器 Agent 负责搜索和详情导航；确定性规则负责仅保留公告、排除结果/候选人/过期信息；PDF/附件进入统一文档读取链路。

## 暂缓站点

- 中国海油：公开搜索和详情正文均可读取，技术可行；群聊样本当日命中较少，作为下一批首选备选。
- 兵器工业：门户能看到采购动态，但询价详情会转入新版系统并要求登录、短信或扫码，且跨多个子域；需要先设计登录态复用和人工接管流程。
- 延长、能源一号等：在前三站稳定后再按群聊命中密度和人工验证成本排序。

## 已完成实现

1. 三站均已进入统一 Site Definition、Browser Journey、详情读取、LLM 筛选和 Collection Report，没有复制新采集管线。
2. 中国石油能够在真实验证码处暂停；已验证会话可读取详情。还需员工在 Windows 安装包完成一次“验证—继续—跨重启复用”验收。
3. 中化已完成真实 DeepSeek 初筛和百度 OCR PDF 回归。
4. 云梦泽已完成 12 个产品词搜索、整卡过期过滤、新窗口详情跟随和 PDF.js 正文回归。
5. 员工试用仍按中国石油 → 中化 → 云梦泽逐站验收；任何误报先作为回归样本修正，再扩大日常使用。

## 单站验收标准

- 连续 3 次巡检能完成，或能在真实验证点准确暂停并从原会话继续。
- 对员工群聊中已发送的相关公告做回放，召回率目标不低于 90%。
- 最终结果不包含候选人公示、中标/成交结果和已过截止时间的信息。
- 命中信息能读取产品、截止时间、关键资质/风险；缺失字段必须明确写“待确认”，不得由模型猜测。
- 每条详情明确标记读取方式：网页/PDF 正文、百度 OCR、PaddleOCR 或未读取到有效正文。
- 一键复制和上传云端继续复用统一 Collection Report，不增加商机卡片、反馈学习等非核心功能。
