# 本地采集助手端到端测试

适用版本：0.1.19

## 测试前准备

1. 在 Windows 电脑安装 `恒化成本地采集助手 Setup 0.1.19.exe`。
2. 首次启动后允许应用打开 Chrome 或 Edge。
3. 进入“模型”，填写：
   - 接口地址：`https://api.deepseek.com`
   - 模型：`deepseek-v4-pro`
   - API Key：使用公司测试密钥，不要把密钥发到群聊或截图中。
4. 点击“保存”，再点击“测试连接”。页面应显示连接成功。

## 国能 E 购

1. 在“采集”中选择“国能E购”。
2. 点击“开始巡检”。
3. 等待约 30-90 秒，期间不要重复点击。
4. 预期：任务自动完成，不要求登录；页面显示采集数量和最终保留数量。
5. 检查保留项必须是当前仍可参与的化工产品采购，不能包含过期公告、设备、工程或结果公示。
6. 点击“复制总结”，粘贴到记事本，检查标题、产品、截止时间和原公告链接。

## 易派客

1. 选择“易派克”并开始巡检。
2. 预期：公开列表自动完成；若模型保留公告，应是实际采购化工产品，而不是项目名称中偶然包含化工词的泵、阀门或电气设备。
3. 确认评标结果、招标结果、中标结果和采购结果没有进入最终总结。
4. 复制总结并与网站当天公开公告人工核对。

## 裕龙

1. 选择“裕龙招投标网”并开始巡检。
2. 遇到网易盾或滑块时，页面应显示“需要你完成验证”，本地浏览器保持打开。
3. 在浏览器中完成人机验证，保持在裕龙搜索结果页。
4. 回到助手点击“验证完成，继续采集”。
5. 如果再次提示验证，重复上一步；如果完成，检查最终结果和公告链接。

## 云端上传

云端配对完成后测试：

1. 选择一个已完成任务。
2. 点击“上传云端”。
3. 页面应提示上传条数。
4. 在 ERP/PocketBase 检查同一公告只出现一次，忽略项不能上传。

如果“上传云端”为灰色，表示当前电脑尚未完成云端配对，不属于采集失败。

## 验收记录

每个站点至少记录：

- 网站当天人工找到的应发群公告数量。
- 助手保留数量。
- 漏报标题。
- 误报标题及误报原因。
- 运行耗时。
- 是否出现登录、滑块、短信或页面异常。

建议连续运行 5 个工作日。重要公告漏报率低于 5%，最终结果误报率低于 10% 后，再逐步替代旧的人工逐站巡检流程。

## 常见问题

- 模型连接失败：检查接口地址、模型名、密钥余额和公司网络。
- 一直显示采集中：等待 90 秒后仍无变化再重启应用，不要连续创建多个相同任务。
- 裕龙验证后仍暂停：确认浏览器停留在公告搜索结果页，而不是首页或登录页。
- 没有相关信息：先与网站当天公告人工核对；如果确有化工品公告，记录为漏报样本，不要直接修改关键词。
