# 本地 Agent 站点深搜策略记录

更新时间：2026-06-27

## 结论

本地 Agent 不能只看首页最新公告。公开 feed 或首页列表全低相关时，应继续按站点 skill 执行产品词深搜；深搜仍失败时，再根据站点类型请求员工登录、验证码或公司网络接管。

## 当前执行链路

```text
公开 feed / 首页列表
  -> 规则词库 + LLM 研判
  -> 若存在可行动商机：输出商机卡片
  -> 若全部低相关：继续 ReAct + Firecrawl 产品词深搜
  -> 若深搜发现详情：打开详情/附件再研判
  -> 若登录、验证码、CA、访问失败：request_human
```

## 需要继续补的能力

- 国能E购：继续扩展详情页/附件深读；当前列表深搜已可用，需验证更多产品词命中质量。
- 裕龙：中国招标投标公共服务平台安全验证后的结果页结构适配；可见列表字段重点为 `noticeName`、`bulletinSource`、`noticeSendTime`、`bulletinID`。
- 延长/中化/中海油：登录态下网络响应捕获和列表 JSON 适配。
- UI：默认展示重点商机；低相关巡检候选折叠在过程/证据中。
- 词库：只有业务确认“能做”的化工品才加高权重；销售、处置、再生、公示类继续强排除。
